## 📖 Sobre o Repositório

Esta é uma coleção organizada dos principais projetos, atividades e exercícios em **Python** desenvolvidos durante o 1º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

Todo o conteúdo foi desenvolvido e testado no **Google Colab**, e cobre desde fundamentos de lógica de programação até projetos aplicados com dados reais do mercado financeiro, automação de planilhas e jogos interativos em console/widgets.

O objetivo deste repositório é documentar minha evolução técnica ao longo do semestre e servir como portfólio inicial na área de programação.

## 📁 Estrutura do Repositório

| Pasta | Descrição | Destaques |
|---|---|---|
| [`jogos-console/`](./jogos-console) | Jogos de lógica em Python | Jogo do Nim (IA com estratégia matemática), Forca (com interface visual via widgets), Jogo do Bixo |
| [`automacao-excel/`](./automacao-excel) | Automação de planilhas com `openpyxl` | Sistema CRUD de alunos, calculadora financeira automatizada |
| [`dashboard-financeiro/`](./dashboard-financeiro) | Análise de dados financeiros reais | Indicadores técnicos (RSI, MACD), métricas de risco (Sharpe Ratio, Drawdown), dados via `yfinance` |
| [`exercicios-logica-python/`](./exercicios-logica-python) | Exercícios fundamentais de lógica | Listas, loops, condicionais, manipulação de arquivos, geração de HTML |

*Cada pasta possui seu próprio README com detalhes técnicos específicos.*

## 🛠️ Tecnologias Utilizadas

- **Python 3** — Linguagem principal
- **Pandas** — Manipulação e análise de dados tabulares
- **NumPy** — Cálculos numéricos e vetoriais
- **Matplotlib / Plotly** — Geração de gráficos e visualizações
- **openpyxl** — Criação, leitura e automação de planilhas Excel
- **yfinance** — Coleta de dados reais do mercado financeiro (Yahoo Finance)
- **ipywidgets** — Criação de interfaces interativas dentro do Google Colab
- **Google Colab** — Ambiente de desenvolvimento em nuvem

## 🚀 Como Executar os Projetos

Todos os códigos foram desenvolvidos para rodar no **Google Colab**, mas também funcionam localmente com Python instalado.

**Google Colab (recomendado):**
1. Acesse [Google Colab](https://colab.research.google.com/)
2. Crie um novo notebook e cole o conteúdo do arquivo `.py` desejado em uma célula
3. Execute com `Shift + Enter`

## 🧠 Aprendizados do 1º Semestre

Este conjunto de projetos representa minha jornada de aprendizado em Python ao longo do semestre, cobrindo:

- Fundamentos sólidos de **lógica de programação** (estruturas condicionais, loops, funções)
- Manipulação de **estruturas de dados** (listas, matrizes, dicionários, list comprehensions)
- **Leitura e escrita de arquivos**, incluindo tratamento de exceções
- Aplicação prática com **dados reais do mercado financeiro**, incluindo cálculo de indicadores técnicos usados por analistas
- **Automação de tarefas repetitivas** com Excel via `openpyxl`
- Criação de **interfaces interativas simples** dentro do Colab usando `ipywidgets`
- Boas práticas de **documentação técnica**, escrevendo relatórios explicando o raciocínio por trás dos algoritmos
