# 🧩 Exercícios de Lógica em Python

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 📖 Sobre

Conjunto de exercícios práticos realizados ao longo das aulas do 1º semestre, cobrindo desde fundamentos até tópicos intermediários de lógica de programação em Python.

## 📚 Conteúdo

| Arquivo | Tópicos Abordados |
|---|---|
| `fundamentos_python.py` | Variáveis, operadores, condicionais, loops, funções, dicionários, tuplas, NumPy básico |
| `listas_e_manipulacao.py` | Métodos de lista (`append`, `insert`, `remove`, `sort`), list comprehensions, matrizes |
| `condicionais_e_loops.py` | Estruturas `if/elif/else`, `while`, simulações financeiras simples com `matplotlib` |
| `slicing_e_matrizes.py` | Slicing avançado de listas (índices negativos, passos, inversão), criação e impressão de matrizes |
| `manipulacao_de_arquivos.py` | Leitura/escrita de arquivos (`open`, modos `r/w/a`), tratamento de exceções, funções com `datetime` |
| `geracao_html_com_python.py` | Geração de páginas HTML estilizadas diretamente via Python (útil para relatórios automatizados) |
| `lista_exercicios_juros.py` | Cálculo de juros com taxas variáveis usando **métodos numéricos de integração** (Regra do Trapézio e Regra de Simpson) |
| `graficos_financeiros.py` | 20 simulações financeiras diferentes visualizadas com `matplotlib` (juros compostos, inflação, amortização, aposentadoria, etc.) |

## 🛠️ Tecnologias

- **Python 3**
- **NumPy** — Operações vetoriais
- **Matplotlib** — Visualização de dados
- **math** — Funções matemáticas (exponencial, para os métodos de integração)

## 🚀 Como Executar

```bash
pip install numpy matplotlib
python fundamentos_python.py
# ou qualquer outro arquivo da pasta
```

## 🧠 Aprendizados

- Consolidação da **lógica de programação** (estruturas de controle, funções)
- Domínio de **estruturas de dados** nativas do Python (listas, tuplas, dicionários, matrizes)
- Introdução a **métodos numéricos** (Regra do Trapézio e Simpson) aplicados a cálculos financeiros
- Manipulação segura de arquivos com tratamento de erros
- Prática constante de **visualização de dados** com matplotlib
